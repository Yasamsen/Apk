ANDROID WEBVIEW BUILDER

Website jadi APK

Buat aplikasi Android ringan dari website HTTPS. Proses build berjalan di GitHub Actions.

Contoh: com.namakamu.aplikasi (huruf kecil, angka, titik).

Unggah PNG/JPG. Ikon akan diperkecil otomatis agar ringan (maksimal file asli 5 MB).

Jika upload dan URL sama-sama diisi, file upload akan dipakai.

Catatan: Versi awal menghasilkan debug APK. Build membutuhkan waktu dan mengikuti kuota gratis GitHub Actions. Jangan masukkan password atau token pribadi di formulir ini.
